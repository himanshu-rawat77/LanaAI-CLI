# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of **Lana AI CLI** and user data seriously. If you discover a potential security vulnerability (e.g. credential leakage, insecure local storage, RPC injection, or sensitive information exposure), please **do not open a public GitHub issue**.

### How to Report
Please report security vulnerabilities responsibly:

1. **Email**: Send details of the vulnerability to `security@helius.dev` or directly to the repository maintainer at `himanshurawatj@gmail.com`.
2. **Subject**: `[SECURITY VULNERABILITY] Lana CLI - <Brief Summary>`
3. **Include**:
   - Description of the vulnerability.
   - Steps to reproduce or a minimal proof of concept (PoC).
   - Potential impact.
   - Any suggested remediations if available.

### What to Expect
- **Initial Response**: We will acknowledge receipt of your report within 48 hours.
- **Triage & Fix**: We will coordinate with you to assess severity and prepare a patched release.
- **Credit**: We will gladly credit you in release notes upon your approval once the patch is published.
